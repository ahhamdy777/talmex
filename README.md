# TALMEX website

Static one-page bilingual site (Arabic / English).

## Publish on GitHub Pages
1. Create a new public repository on GitHub, e.g. `talmex`.
2. Upload everything in this folder (index.html + assets/) to the repository root.
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / root → Save.
4. After ~1 minute the site is live at `https://<your-username>.github.io/talmex/`.
5. Use that address for the QR code on the business card.

English version direct link: add `#en` at the end of the address.
